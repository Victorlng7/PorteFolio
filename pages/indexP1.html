Le Contexte

Réalisé dans le cadre de ma formation en BUT Informatique, ce projet avait pour objectif la conception d'un système complet création, modification, supression d'interventions

Capture d'écran de l'interface

Fonctionnalités & Défis Techniques

💻

Front-end Vanilla & Typage Strict

Développement de l'interface entièrement en HTML, CSS et TypeScript sans framework. Ce parti pris technique permet une maîtrise totale de la manipulation du DOM et garantit un code robuste et maintenable grâce au typage fort.

🗄️

API REST PHP & Base SQL

Conception du back-end avec une base de données relationnelle SQL pour gérer l'état des interveitons et les délais de celle-ci. La communication avec le client s'effectue via une API métier développée sur-mesure en PHP.

📐

Maquettage & UI/UX (Whimsical)

Avant d'écrire la moindre ligne de code, l'architecture visuelle et le parcours utilisateur ont été pensés, schématisés et prototypés sur Whimsical pour garantir une interface ergonomique et un développement fluide.
