Application Météo Vue.js

Projet personnel de consommation d'API en temps réel

Vue.js JavaScript API REST Front-end

Le Contexte

Ce projet personnel est né d'une volonté d'approfondir mes compétences sur le framework Vue.js et d'explorer la gestion de données asynchrones.

L'utilisateur peut saisir le nom de n'importe quelle ville ou village dans le monde. L'application interroge alors instantanément une API météorologique externe pour récupérer les données actuelles (température, conditions, humidité) et met à jour l'interface dynamiquement sans aucun rechargement de page.

Détails Techniques & Fonctionnalités

⚡

Réactivité avec Vue.js

Utilisation du système de réactivité de Vue.js (comme v-model pour la barre de recherche) pour lier instantanément les saisies de l'utilisateur aux variables d'état du composant, offrant une interface extrêmement fluide.

🌐

Consommation d'API REST

Gestion des requêtes HTTP asynchrones via fetch vers une API externe. Traitement des réponses au format JSON, gestion des promesses et interception des erreurs (par exemple, si la ville saisie n'existe pas).

🔐

Architecture & Sécurité (Axes d'amélioration)

Ce projet ayant été pensé comme un exercice purement Front-End, la clé d'API est actuellement appelée côté client. J'ai conscience que pour une mise en production réelle, la bonne pratique exigerait la création d'un micro-backend (Node.js ou PHP) afin de stocker cette clé de manière sécurisée dans un fichier .env et de masquer les requêtes au navigateur.
